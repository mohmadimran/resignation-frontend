# 🧾 MERN Stack Resignation Management System  
[Live Demo](https://resignation-frontend.vercel.app/) 

## Overview
The **Resignation Management System** is a full-stack MERN (MongoDB, Express.js, React.js, Node.js) application designed to streamline employee resignation and exit processes.  
It enables **employees** to submit resignations and fill exit questionnaires, while **HR/Admins** can manage approvals, schedule exit interviews, and track overall resignation workflows.

## Features

### 👩‍💼 Employee Features
- Employee registration and login
- Submit resignation request with reason and last working day
- View resignation status and HR remarks
- Fill out exit interview questionnaire

### 🧑‍💻 Admin (HR) Features
- HR/Admin login and dashboard
- View all resignation requests
- Approve or reject resignations with remarks
- Manage employee exit interviews
- View reports of resignations and exit data
